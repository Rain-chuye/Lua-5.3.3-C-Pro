# Lua-5.3.3-C-Pro (初叶定制版) 核心文档

## 1. 概述
本项目是基于 Lua 5.3.3 的深度魔改版本，专为安全性与语法效率设计。主要特性包括：
- **增强型词法分析器 (llex)**: 支持 C/Java 风格的操作符、复合赋值、Lambda 短语法。
- **高级语法结构 (lparser)**: 内置 `switch-case`、`defer`、`when`、`continue` 等高级控制流。
- **虚拟机混淆与优化 (lvm)**: 支持指令融合、虚拟化代码块 (VMP) 以及指令级动态加解密。
- **字节码安全**: 深度集成了 SHA-256 完整性校验（魔改版）和字符串全自动混淆。

---

## 2. 词法扩展 (llex)

### 2.1 新增操作符
| 符号 | 等价于 | 描述 |
| :--- | :--- | :--- |
| `!` | `not` | 逻辑非 |
| `!=` | `~=` | 不等于 |
| `&&` | `and` | 逻辑与 |
| `||` | `or` | 逻辑或 |
| `$` | `local` | 局部变量声明缩写 |
| `@` | `::` | 标签声明 (Label) |
| `//` | `//` | 整除 (Lua 5.3 标准，但在本版中强化) |

### 2.2 复合赋值
支持以下 C 风格的复合赋值操作：
`+=`, `-=`, `*=`, `/=`, `//=`, `%=`, `^=`, `..=`, `&=`, `|=`, `<<=`, `>>=`

**示例代码:**
```lua
$ a = 10
a += 5  -- 等同于 a = a + 5
$ s = "Hello"
s ..= " World"
print(s)  -- Hello World
```

### 2.3 UTF-8 短转义
支持更简洁的 Unicode 转义：
`\u{XXXX}` (标准) 及其变体。

## 3. 语法扩展 (lparser)

### 3.1 Lambda 表达式 (匿名函数)
使用 `\` 启动，支持 `->` (带返回) 或 `=>` (单条语句)。

**语法格式:**
- `\参数 -> 表达式`
- `\参数 => 语句`

**事例代码:**
```lua
$ add = \x, y -> x + y
$ sayHello = \name => print("Hello, "..name)

print(add(10, 20))    -- 30
sayHello("Jules")     -- Hello, Jules
```

### 3.2 Switch-Case 语句
支持更直观的多分支选择。

**语法格式:**
```lua
switch 变量 do
  case 值1 then
    -- 执行代码
  case 值2, 值3 then
    -- 支持多值匹配
  default
    -- 默认逻辑
end
```

### 3.3 Defer 语句
用于在作用域结束时延迟执行代码（类似于 Go 语言），常用于资源释放。

**事例代码:**
```lua
function test()
  $ f = io.open("data.txt", "r")
  defer f:close() end

  -- 读取文件的逻辑，无论是否报错或提前返回，f:close() 都会执行
end
```

### 3.4 When 语句
一种更简洁的条件分支。

**事例代码:**
```lua
when x > 10 then
  print("Large")
case x > 5 then
  print("Medium")
else
  print("Small")
end
```

### 3.5 Continue 语句
在 `for`、`while`、`repeat` 循环中支持 `continue`。

## 4. 虚拟机安全性与 VMP

### 4.1 指令虚拟化 (OP_VIRTUAL)
编译器会将部分高频或敏感指令块转换为虚拟化字节码，存储在 Proto 的 `vcode` 区域。
VM 执行到 `OP_VIRTUAL` 时，会进入内部的微型解析引擎执行这些虚拟指令，极大地增加了逆向分析的难度。

### 4.2 SHA-256 完整性校验
字节码在 Dump 时会计算全文件的魔改版 SHA-256 哈希值并附加在末尾。
加载 (Undump) 时会重新计算并校验，若被篡改则拒绝加载：
`error: 完整性校验失败 (SHA-256 不匹配) 预编译代码块`

---

## 5. VM 分析与开发建议
本 VM 采用了指令融合技术（如 `OP_FAST_DIST` 用于加速坐标距离计算），在处理特定数学运算时比原版 Lua 更快。

**建议:**
由于核心逻辑已被深度修改，建议在新增功能时优先参考 `lparser.c` 中的 `statement` 函数，了解语法糖的解析过程。
